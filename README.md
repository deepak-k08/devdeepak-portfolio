# Dev Deepak Portfolio

Personal portfolio built with Next.js.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy

Push to GitHub and import the repository into Vercel. Then add `devdeepak.in` in Vercel's Domains settings and follow the DNS instructions in GoDaddy.

## Before launch

Replace the placeholder GitHub/LinkedIn/Resume links and update the project descriptions/contact email if needed.
